# 我的力量日志

现有站点：https://wangrunnan0608-beep.github.io/Training-Log/

手机主屏幕 App 与 Safari 分别保存数据和 AI 设置。在常用入口设置 Worker 地址和访问口令，勾选“在本机记住访问口令”后保存。访问口令属于敏感凭据，保存在网页本地存储中；不要填写 DeepSeek API Key。

升级前导出 JSON；升级后关闭并重新打开应用，必要时刷新一次。不要清除网站数据。遇到相同 ID 内容冲突时导入会停止，原有记录保留。

## 本地验证

运行 `node --check app.js`、`node tests/settings.test.cjs`、`node tests/import.test.cjs`。浏览器测试的运行依赖由本机 Codex 提供，当前脚本使用 Windows Edge。旧备份测试：`node tests/legacy.test.cjs <本地交接包路径>`；训练记录只在内存中读取。

## v4.2.0

日常建议默认只发送最近4次同类训练的实际数据，取消历史备注关键词拦截；可主动勾选本次分享备注。提示词以稳固和逐步提升为原则。生成后点击使用计划，动作、组数、重量带入草稿，实际次数/左右次数/秒数留空。AI目标独立保存和显示，只有实际完成的组计入历史。已有草稿或历史编辑时阻止覆盖，计划和草稿刷新后保留。完成训练按钮改为居中。

验证：运行 node tests/plan.test.cjs，模拟AI返回，覆盖备注隐私、重新生成、草稿保护、左右次数/秒数、刷新恢复及只保存已完成组。真实模型输出质量和iPhone仍需实际使用验收。

## v4.3.0

新增DeepSeek直连模式（默认），固定请求https://api.deepseek.com/chat/completions。用户在手机输入自己的Key，可选仅会话或在本机记住，也可清除。Key不写入源码、不进入训练JSON备份、不发送给Cloudflare。Worker保留为独立备用模式，凭据分开保存。默认不自动切换请求路径。仓库可见性不改变。

模拟验证：node tests/direct.test.cjs，检查目标URL、认证头、记住/清除、会话过期及导出排除Key。真实Key完整调用与iPhone无VPN网络尚需用户实测。

## v4.3.1

使用AI计划时弹窗确认覆盖。历史编辑中可继续编辑，或在最终确认后保存历史修改并替换当前计划；取消不保存、不退出。保存失败则保持编辑状态并恢复原草稿存储。确认覆盖前保留一份本机恢复快照strength-journal-replaced-plan-v1（不包含连接凭据）。提示移到屏幕下方、避开底栏与安全区域，使用实色底白字。计划浏览器测试覆盖这些分支及存储失败回滚。

## v4.3.2

去掉卡片内重复操作，只保留底部添加动作/添加组。恢复自定义名称（重量kg+次数），名称在草稿/历史保留，可再次选择并绘制历史曲线。历史删除需依次通过三次确认，任一步取消均不删除，存储失败保留记录；若删除正在编辑的记录，成功后恢复原当前草稿。测试：node tests/custom-delete.test.cjs。

## v4.3.3

历史按日期分组，可勾选一天或多天并删除这些日期下的全部训练；显示选中天数/记录数，三次确认均列出删除范围。保留单条删除入口。取消或写入失败不删除；删除正在编辑的记录后恢复原当前草稿。当天保存和文件导出流程不变。验证：node tests/date-delete.test.cjs，包括同日多记录、跨日选择、未选日期保留、存储失败、编辑状态恢复及曲线重算。
